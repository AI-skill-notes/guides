꼭 알아 둘 것

  • 이 제작 프롬프트에는 'Pre-rendering the film and embedding it in the file is allowed.'(영상을 미리 만들어 파일에 넣어도 된다), 'Use any tools, libraries, references, guides, literally anything.'(도구는 뭐든 써도 된다)라고 적혀 있어요. 브라우저가 코드로 그때그때 그리는 애니메이션이 아니어도 된다는 뜻이에요.
  • 우리가 'The Moss Keeper'의 index.html(48,259,444바이트)을 직접 열어 보니, 화면을 띄우는 코드는 약 9KB(9,196바이트)이고 나머지는 파일 안에 넣은 동영상(MP4 35,960,319바이트)과 포스터 그림이었어요.
