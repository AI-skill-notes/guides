영화 스킬 실습: 코드로만 만든 매트릭스 오마주 (AI스킬노트 실습 2, 2026-10-26)

Claude Code에 영화 스킬 lemo-opuscar를 깔고, 같은 요청을 스킬을 쓴 클로드와 안 쓴 클로드에게 한 번씩 맡긴 실험 자료예요.

1. 설치 (명령어 두 줄)

claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab

먼저 깔아 둘 것: Node, ffmpeg, Python(또는 uv). 윈도는 공식 안내가 WSL을 권해요. 저희는 윈도에서 파이썬 경로 문제로 한 번 막혔어요.

2. 실험에 쓴 요청문 (그대로 복사해서 쓰세요)

40초짜리 영화 한 편을 코드로만 만들어 줘. 영상 생성 AI, 이미지 생성 AI, 사진, 스톡 영상은 쓰지 않는다.

주제: 영화 '매트릭스'(1999) 오마주. 초록색 옛날 모니터(CRT) 화면, 쏟아지는 글자, 빨간 약과 파란 약 중 하나를 고르는 장면, 주인공이 몸을 뒤로 젖혀 느린 총알을 피하고 카메라가 그 주위를 도는 '불릿 타임' 장면이 꼭 들어가야 한다. 원작의 영상·음악·대사·배우 얼굴·로고는 쓰지 않는다(분위기와 장면 문법만 빌린다).

화면 글자는 한국어로. 내레이션 음성은 없어도 된다. 음악과 효과음은 넣는다.

결과물: 이 폴더에 film.mp4 (1920x1080, 24fps 이상, 소리 포함) 와 poster.jpg.
나는 중간에 답할 수 없으니 질문하지 말고 합리적인 기본값으로 끝까지 진행해.

요청할 때는 원하는 스타일 이름과 꼭 들어갈 장면을 구체적으로 적어 주세요.

3. 실험 결과 (실험 10/25, claude-opus-5-5, 요청마다 한 번씩)

스킬 없이 영화 스킬
걸린 시간 58.4분 30.4분
비용(API 정가 환산) 8.42달러 7.69달러
도구 호출 134번 127번
소리 크기(유튜브 기준 -14 LUFS) -15.4 LUFS -13.9 LUFS
블라인드 심사(장면 네 장만 보고) 6표 0표

조건: 빈 폴더 두 개, 같은 모델과 설정, 다른 건 스킬 폴더 하나. 한 번씩 돌린 결과라 다시 하면 달라질 수 있고, 심사위원도 AI예요.

정리: 스킬은 더 멋진 그림을 보장하지 않았어요. 대신 시간을 줄이고 소리 기준을 지켰어요. 멋은 스타일 고르기와 사람 눈의 몫이에요.

4. 저작권 선

원작 영화의 영상·음악·대사·배우 얼굴·로고는 쓰지 마세요. 분위기와 장면 문법만 빌리는 오마주예요.
