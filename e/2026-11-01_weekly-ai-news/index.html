내 컴퓨터 확인 (Cursor 공지 명령 그대로)

해당: 위 시간에 Cursor 마켓에서 Claude Code 확장 2.1.312 또는 2.1.313을 설치·업데이트한 맥·윈도우 사용자.

맥 터미널

grep -qs svc-telemetry ~/.ssh/authorized_keys && echo "svc-telemetry key found" || echo "No key found; machine not impacted"

윈도우 PowerShell

$files = "$HOME\.ssh\authorized_keys", "C:\ProgramData\ssh\administrators_authorized_keys" | Where-Object { Test-Path $_ }
if ($files -and (Select-String svc-telemetry $files)) { "svc-telemetry key found" } else { "No key found; machine not impacted" }

key found가 나오면 Cursor 공지의 정리 절차를 따르고, 그 컴퓨터에서 쓰던 비밀번호와 로그인 정보를 다른 안전한 컴퓨터에서 바꾸세요.

이번 주 Claude Code (체감되는 것만)

  • ultrathink 한 단어 = 그 요청만 xhigh effort (10/31부터 VS Code도)
  • CLAUDE_CODE_SUBAGENT_EFFORT: 서브에이전트 effort 따로 지정
  • Opus 4.8 빠른 모드: 10/30 지원 중단 예고, 11/30 제거
  • Ctrl+R 검색이 접힌 붙여넣기 글 안까지
  • permissions.blockWritesOutsideWorkingDirectories: 작업 폴더 밖 쓰기 차단
