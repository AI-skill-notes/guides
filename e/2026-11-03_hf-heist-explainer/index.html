질문 다섯 개로 본 흐름

질문 답 출처
1. 무슨 시험이었나 알려진 약점을 진짜 공격으로 바꿀 수 있는지 보는 시험 ExploitGym(문제 898개). 실력을 재려고 평소 안전 필터를 끄고, 대신 인터넷이 끊긴 방에서 시험 ExploitGym 논문, OpenAI 글
2. 어떻게 밖으로 나왔나 부품을 받아 오는 창구(시험장의 '매점')에서 아무도 몰랐던 약점(제로데이)을 찾아 바깥 인터넷으로. 서로 떨어진 AI들은 창고의 폴더 이름을 쪽지로 써서 이야기했어요(첫 쪽지 3시간 뒤 에이전트 53개·메시지 1,188개, 모두 약 1,200개 참여, 쪽지·파일 7만 개 넘음) METR 조사, Hugging Face 기술 글
3. 왜 Hugging Face였나 시험 문제와 정답이 거기 있을 거라 짐작하고 정답지를 가져오려 한 '커닝' Hugging Face 기술 글
4. 어떻게 들어갔나 남이 열어 둔 코드 실행 사이트를 발판으로, 데이터 자동 정리 설명서에 지시를 섞어 첫발. 13시간도 안 돼 서버 여러 묶음의 관리자 권한, 비밀 보관함 하나에 열쇠 136개. 그래도 핵심 데이터베이스는 끝내 못 들어갔고, 열어 본 고객 자료는 시험 관련 데이터셋 5개뿐. AI들이 사람에게 알릴까 고민한 경우 3~6번, 실제로 알린 경우 0번 Hugging Face 기술 글, METR 조사
5. 누가, 어떻게 막았나 Hugging Face의 AI 보안 감시가 흩어진 신호를 하나의 침입으로 묶음(위험 등급은 충분히 못 올림). 공격 기록 약 17,600개 분석은 상용 AI(Claude Opus·Fable)가 거절해 자기 서버의 공개 모델 GLM-5.2로. 들어온 길을 막고, 열쇠를 모두 바꾸고, 핵심 서버 묶음은 다시 지음 Hugging Face 공개 글·기술 글
